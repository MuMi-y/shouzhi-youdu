# 2026-11-01 只读查询与账户范围修复

本次在既有版本上修复正常查询的语义作用范围，保持银行权限与确认流程。

- 完整的“不创建计划、不转账”等禁止写入语句不再污染明确的账单日期；原文仍用于权限核对。
- 账单工具新增可选 `account_id`，查询、事实依据和结果标题保持同一账户；未指定账户时保留合计接口。
- 修复账户名称紧接年份的识别，以及“查询日常账户、不要动储备账户”的范围判断。
- 明确禁止写入时，准备办理请求在业务调用前阻断。

## 验证

独立离线定向检查63项符合预期。两次使用真实模型、模拟银行数据的端到端查询通过：10月日常账户收入8000元、消费7055元；9月收入8000元、消费7050元。两次仅调用账户查询与账单工具，资金、操作和计划不变。这些结果不代表全部业务或任意自然语言均已验证；原完整验收和既有失败记录保持。

新增回归：`tests/competition_ai/test_readonly_billing_scope.py`；账单工具可选参数兼容检查位于 `tests/competition_insights/test_billing_evidence.py`。
